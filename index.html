1 · Dataset

Four noisy clouds

We sample 25 points around each corner of the square $[-1,1]^2$ with Gaussian noise $\sigma = 0.28$. Opposite corners share a label: bottom-left and top-right are class 0, the other two are class 1.

This is the XOR pattern from TensorFlow Playground: no single straight line can separate the two colours. A hidden layer is needed.

scroll slowly — the clouds form as you go
1 · Dataset

Split before you fit

Each cloud gives 20 points to training and 5 to test: an 80/20 split with both classes balanced (40/40 and 10/10).

Gradient descent will only ever see the 80 filled points. The 20 rings are held out until the very end, when the trained model is frozen.

2 · The network

Two inputs, two hidden units, one output

$$\mathbf a = W\mathbf x+\mathbf b,\qquad \mathbf h=\sigma(\mathbf a)$$ $$z=\mathbf v^\top\mathbf h+c,\qquad \hat p=\sigma(z)$$

That is 9 trainable numbers: four in $W$, two in $\mathbf b$, two in $\mathbf v$, one $c$. The values $\mathbf a,\mathbf h, z,\hat p$ are computed, not learned.

Edge thickness ∝ |weight|, dashed = negative. These are the slide parameters: $W = \left(\begin{smallmatrix}0.5&0.5\\-0.5&-0.5\end{smallmatrix}\right)$, $\mathbf b = \mathbf 0$, $\mathbf v = (1,-1)$, $c = 0$.

2 · The network

Same function, different numbers

Before training, the network's predictions depend entirely on where its parameters start. Here: the slide parameters and two random draws (default_rng(0), default_rng(1)).

Background colour = $\hat p$ at that location; the black curve is $\hat p = 0.5$, the decision boundary. None of them solves XOR — and we judge them on the training set only, never on test scores.

3 · Loss

How wrong is $\hat p$?

$$L=-y\log\hat p-(1-y)\log(1-\hat p)$$

Binary cross-entropy. For $y=1$ it reduces to $-\log\hat p$: zero when the network is confidently right, exploding as $\hat p\to 0$. Scroll to drag the prediction towards the wrong answer.

Sigmoid and BCE are a lucky pair — the derivative w.r.t. the output pre-activation is just the error:

$$\delta_z=\frac{\partial L}{\partial z}=\hat p-y$$
backward 4 · Walk the chain back

Blame flows right to left

  1. $\delta_z = \hat p - y$
  2. $\nabla_{\mathbf v}L=\delta_z\mathbf h,\quad \nabla_cL=\delta_z$
  3. $\boldsymbol\delta_h=\delta_z\,\mathbf v$
  4. $\boldsymbol\delta_a=\boldsymbol\delta_h\odot\mathbf h\odot(1-\mathbf h)$  (σ′)
  5. $\nabla_WL=\boldsymbol\delta_a\mathbf x^\top,\quad \nabla_{\mathbf b}L=\boldsymbol\delta_a$

Every formula reads only from the cache ($\mathbf x,\mathbf h,\hat p$) and from a $\delta$ computed one step earlier.

backward 4 · Why it is cheap

Compute once, reuse many times

$\delta_z$ is computed once and used five times: for $\nabla_c$, $\nabla_{v_1}$, $\nabla_{v_2}$, $\delta_{h_1}$, $\delta_{h_2}$.

Each $\delta_{a_i}$ is computed once and feeds three gradients: $\nabla_{W_{i1}}$, $\nabla_{W_{i2}}$, $\nabla_{b_i}$.

Differentiating each of the 9 parameters separately would redo the same chain-rule product again and again. Backpropagation is the chain rule plus bookkeeping: shared prefixes are computed once and cached.

5 · One gradient-descent update

Everyone moves at once

$$\theta_{t+1}=\theta_t-\eta\,\nabla_\theta L(\theta_t),\qquad \eta = 0.1$$

All 9 gradients were computed at the same $\theta_t$; only then do all parameters move together. Scroll and watch $\hat p$ creep towards $y=1$ while the loss drops.

Try the x = (0, 0) toggle above: then $\nabla_W L=\boldsymbol\delta_a\mathbf x^\top = 0$. An input that is zero gives its weights no blame, so $W$ does not move — exactly what the notebook's run shows.

5 · Zoom out

Following a slope

Slice the loss along the direction $-\nabla L$: plot $L(\theta - \eta\,\nabla L)$ as a function of the step size $\eta$.

At $\eta=0$ the slope is $-\lVert\nabla L\rVert^2$ — the steepest way down. The update we just did is the ball rolling to $\eta = 0.1$: a small, safe step along the tangent.

6 · Reuse the same functions on the training set

Average 80 opinions

Each training point runs the same forward and backward and votes for a gradient $g_i$. The update uses their mean:

$$\nabla_\theta J=\frac{1}{n_{\text{train}}}\sum_{i=1}^{n_{\text{train}}}g_i$$

Bars: solid = running mean, outline = the current point's vote. Single votes disagree wildly; the mean is the consensus. No new backward rule, and no test point ever enters this average.

7 · The training loop

2,000 updates

Restart from the slide parameters. Each tick: mean gradient over all 80 points, then one update with $\eta = 0.5$. 2,000 updates = 2,000 epochs = 160,000 example presentations.

The dashed lines are where each hidden unit's pre-activation is zero ($h_i = \tfrac12$). Watch them rotate into two parallel diagonals: the output unit fires when $h_1$ is on but $h_2$ is off — the band between the lines is class 1. XOR, solved by combining two linear cuts.

7 · Held-out evaluation

The test set's verdict

Parameters are now frozen. The 20 rings finally enter: we only run the forward pass on them, no updates.

Train fits almost perfectly; test is a bit worse — one ring sits on the wrong side (circled). That is evidence for this split and distribution, not a guarantee for every input or seed.

8 · Failure case

Start at zero, stay at zero

Initialise all 9 parameters to 0. Then $\mathbf h = (0.5, 0.5)$ and $\hat p = 0.5$ for every input.

  • $\mathbf v = 0 \Rightarrow \boldsymbol\delta_a=\delta_z\mathbf v\odot\mathbf h\odot(1-\mathbf h)=0$: $W$ and $\mathbf b$ get no gradient.
  • Balanced data $\Rightarrow$ the mean of $\hat p - y$ is exactly 0: $\mathbf v$ and $c$ get none either.

2,000 updates, zero movement; loss frozen at $\log 2 \approx 0.693$. Even on unbalanced data the two hidden units would stay identical twins forever: zero init never breaks the symmetry.

recap

Four moves, repeated

Everything above is these four functions from the notebook, called in a loop.

forward

Compute & cache

$$\mathbf h=\sigma(W\mathbf x+\mathbf b)$$$$\hat p=\sigma(\mathbf v^\top\mathbf h+c)$$

Keep $\mathbf x,\mathbf a,\mathbf h,z,\hat p$ — the backward pass reads them.

loss

Measure the error

$$L=-y\log\hat p-(1-y)\log(1-\hat p)$$

With a sigmoid output, $\partial L/\partial z = \hat p - y$.

backward

Reuse the deltas

$$\boldsymbol\delta_a=\delta_z\mathbf v\odot\mathbf h\odot(1-\mathbf h)$$$$\nabla_W=\boldsymbol\delta_a\mathbf x^\top$$

Each $\delta$ computed once, shared by every parameter downstream of it.

update

Step downhill

$$\theta\leftarrow\theta-\eta\,\frac1n\sum_i g_i$$

Average over the training set, all parameters at once. Never touch the test set.

Every number on this page is recomputed live in float64 from the notebook's dataset (NumPy seed 42). Matches the notebook: train BCE 0.714 → 0.018, test accuracy 0.95.
